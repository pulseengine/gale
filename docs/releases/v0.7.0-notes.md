# v0.7.0 — "Run It"

The composed OS had never been executed as one OS. Every claim about it was
**structural** — one scheduler and one clock inferred from import routing and source
ownership, not from watching a handle survive a call. This release ran it, dissolved
it, and measured what that cost.

## The falsification statement

**Claim under test:** the fused `gust:os` component behaves as one OS — a handle from
`spawn.start()` is valid in `timer.sleep()` and `exec.state()`, and one clock sits
behind `time.now()` and the timer's deadlines.

**It survived — and running it refuted two things we believed on the way.** That is
the release's actual content; a demo that only confirms is worth less.

## What shipped

**E1 — the composite EXECUTED.** A handle observed crossing `spawn -> timer -> exec`.
One scheduler and one clock are now **observed**, not inferred.
(`REQ-/VER-OS-COMPOSITE-EXEC-001`)

**E2 — the composite DISSOLVED.** The whole OS as one Cortex-M3 relocatable object:

    text 5 384   data 1 580   bss 3 620
    SRAM  5 200 B of the STM32F100RB's 8 192   (63%)
    seam  undefined = EXACTLY { poll-task, read32, write32 }
    arena 1 wasm page

Gated on the seam set *and* its negative control — an object with **no** undefined
symbols must be refused, and the build exits 4 if that control ever passes.
(`REQ-/VER-OS-COMPOSITE-DISSOLVE-001`)

**HM — value-domain Health Monitor + failsafe FSM**, Verus/Kani with per-trigger fault
injection. (`REQ-/VER-OS-HM-001`)

## What running it refuted

**A miscompile that four static gates passed (#270).** `gust_iso_probe` executed the
dissolved isolation core on qemu and failed `iso-frame`: synth 0.52.0 miscompiled
`set-window`. Static gates — disjointness, the seam set, symbol counts — all passed.
Only execution caught it. Fixed by the pin bump to synth 0.57.0, measured both ways on
identical inputs: **8/9 -> 9/9**, with `.text` 12 bytes *smaller*.

**A contract violation the type system could not see (#283).** `timer.sleep` returned
`0` — success — for out-of-range, non-id and already-`Done` handles, where the WIT
specifies `0xFFFFFFFF`. Callers were told a wake was armed that would never fire.
Fixed by querying `gust:sched/tasks.state` before arming; no WIT or verified-core
change needed. Harness deviations `3 -> 0`, and the CI count-pin dropped with it.

**A fusion that fit because it was wrong (#266/#280).** The isolation core's
`meld fuse --memory shared` build merged memories *without rebasing*: four overlapping
data-segment pairs, one of them a 320-byte `RegionTable` over another module's `.data`.
It shipped because it was the only build that fit — the correct alternatives were 16x
to 272x over budget. meld 0.48's `--pack-rebase` + `--share-stack` closed it. The
correct build is **532 B larger than the incorrect one, and both fit**: 4 236 B (51%),
disjoint, gated.

## What this release does NOT claim

**It does not claim the measuring half.** This was planned as *"Run It, Then Measure
It"*. The measuring reached:

- **T2 object-code verification — 51% union coverage, 49% gap.** Computable for the
  first time (synth#933 and #935 closed), then **corrected** on a clean rebuild:
  52%/48% -> 51%/49%, denominator 477 -> 496. A categorical claim was withdrawn —
  "every arithmetic and comparison rule these objects use is covered" is false; a
  17-instance tail has neither obligation nor SMT coverage.
- **T4 static WCET — 3 of 31 functions bounded.**

Both remainders are upstream: **synth#1057** (control-flow obligations, scoped to synth
v0.60), **scry#144** + **synth#1063** (loop-bound inference and its join key). The
triad is re-pointed to **v0.7.2 "Measure It"** — explicitly, on all six artifacts, so
nothing queries as closed that is not.

**Other standing limits.** The four native seam atoms remain trusted code outside
BIN-VERIFY and MC/DC. Execution is qemu `lm3s6965evb`, not silicon. The shadow-stack
budget is asserted, not proven. `i32_const_correct` was `Admitted` when first measured.
